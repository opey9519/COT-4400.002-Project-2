# COT-4400.002-Project-2
(Divide &amp; Conquer, Greedy, Dynamic Programming)

## Overview
### Summary
Contains 3 algorithm paradigm implementations:
- MergeSort
- Greedy Algorithm
- Dynamic Programming

### Code Overview
The project is set up in a way where you can access each method algorithm method within the ```main``` function.  
Each function currently ```MergeSort```, ```DP```, ```Greedy``` is set up in a modular way for easy testing with test cases provided [instructions](COT4400-Project-2-instructions.pdf).


## Set up
1. Create Python Virtual Environment
   ```
     python3 -m venv .venv
   ```
2. Activate Python Virtual Environment
   ```
     source .venv/bin/activate
   ```
